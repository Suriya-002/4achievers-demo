Curriculum

A Structured, Industry-Mapped Syllabus

9 progressive modules that take you from fundamentals to a deployable capstone project.

Python essentials, data types, control flow, functions and OOP. Core statistics & probability: descriptive stats, distributions, hypothesis testing, correlation and sampling — the mathematical backbone every data scientist needs.

Loading, cleaning and transforming data with Pandas and NumPy. Handling missing values, merging & grouping datasets, feature engineering, and working efficiently with large tabular data from CSVs, Excel and SQL.

Exploratory Data Analysis techniques to uncover patterns and outliers. Build insightful charts with Matplotlib and Seaborn, and create interactive business dashboards using Power BI for stakeholders.

Supervised and unsupervised learning with Scikit-learn — regression, classification, decision trees, random forests, SVM, clustering and dimensionality reduction. Model selection, cross-validation and hyperparameter tuning.

Neural network fundamentals with TensorFlow and Keras. Build and train ANNs, CNNs for image tasks and RNNs for sequence data. Understand backpropagation, activation functions, optimisers and regularisation.

Text preprocessing, tokenisation, embeddings and vectorisation. Build models for sentiment analysis, text classification and named-entity recognition, and understand transformer architectures behind modern language models.

Work with Large Language Models, prompt engineering, embeddings and vector databases. Build retrieval-augmented generation (RAG) pipelines and deploy your own GenAI chatbot for real business use cases.

Take models from notebook to production. Version control with Git, build APIs with Flask/FastAPI, containerise with Docker, and set up monitoring, CI/CD and cloud deployment for reliable ML systems.

An end-to-end capstone project on a real dataset, mentored from problem statement to deployment. Combined with resume building, portfolio polishing, mock interviews and placement readiness sessions.
