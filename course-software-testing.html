Program Overview

Software quality is non-negotiable for every product team in India, and skilled QA engineers who can both design test cases and automate them are in short supply. This program is built to make you exactly that professional.

Curriculum

A Module-by-Module Roadmap to QA Mastery

Nine structured modules take you from testing basics to a production-grade automation framework.

Introduction to software testing, why quality matters, SDLC models (Waterfall, Agile, V-model), the Software Testing Life Cycle, levels of testing, verification vs validation, QA vs QC, and the role of a tester in an Agile Scrum team.

Writing effective test cases and scenarios, test case design techniques (boundary value, equivalence partitioning, decision tables), requirement traceability matrix, defect life cycle, severity vs priority, and bug reporting using JIRA.

Java basics, variables and data types, operators, loops and conditions, OOP concepts (classes, objects, inheritance, polymorphism, encapsulation), collections, exception handling, and writing clean reusable code specifically for automation.

Selenium architecture, locators (ID, XPath, CSS), WebDriver commands, handling web elements, dropdowns, alerts, frames, windows, waits (implicit, explicit, fluent), Actions class, and automating real web application flows.

TestNG annotations, assertions, grouping, prioritisation, parallel execution, parameterisation, data providers, listeners, and generating detailed TestNG HTML and XML reports.

Page Object Model design pattern, Page Factory, data-driven framework with Apache POI and Excel, hybrid frameworks, Maven project structure, reusable utilities, and logging with Log4j for scalable, maintainable test suites.

REST API fundamentals, HTTP methods and status codes, manual API testing with Postman, collections and environments, then automating API tests with REST Assured — request/response validation, JSON parsing and schema validation.

Version control with Git and GitHub, branching and collaboration, setting up Jenkins, creating build jobs, scheduling automated test runs, integrating Maven and TestNG with Jenkins, and continuous integration best practices.

Build a complete end-to-end automation framework for a real web application integrated with CI/CD, plus SQL for database testing, resume building, mock interviews, and the most-asked QA interview questions with detailed answers.
