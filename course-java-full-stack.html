Curriculum

A 10-Module Roadmap to Full Stack

Carefully sequenced so every concept builds on the last. Each module is live, mentor-led and project-backed.

Variables, data types, operators, control flow, methods and arrays. Deep dive into object-oriented programming: classes, objects, inheritance, polymorphism, abstraction and encapsulation — the mental model everything else rests on.

List, Set, Map and Queue implementations, iterators, generics and the Streams API. Robust error handling with try/catch/finally, custom exceptions, and writing resilient code that fails gracefully.

Relational database fundamentals with MySQL — tables, joins, indexing, constraints and queries. Connect Java to databases via JDBC, run prepared statements, and manage transactions safely.

Inversion of control, dependency injection and Spring beans. Build rapid, production-ready apps with Spring Boot: auto-configuration, starters, profiles, properties and the embedded server workflow.

Object-relational mapping with Hibernate and Spring Data JPA. Entity mapping, one-to-many and many-to-many relationships, repositories, queries, lazy vs eager loading and caching strategies.

Design clean REST endpoints with proper HTTP semantics, status codes, versioning and validation. Handle requests/responses with DTOs, document APIs with Swagger, and secure them with Spring Security & JWT.

Break applications into independent services. Service discovery, API gateways, inter-service communication, configuration servers, circuit breakers and resilience patterns with the Spring Cloud ecosystem.

Modern JavaScript (ES6+), then React: components, props, state, hooks, routing and consuming REST APIs. Build a responsive single-page UI that talks to your Spring Boot backend.

Git workflows and collaboration, containerising services with Docker, and deploying your full stack application to AWS. Environment configuration, logging and a taste of CI/CD pipelines.

Bring everything together in an end-to-end capstone built and reviewed with a mentor. Parallel interview preparation: data structures & algorithms, system design basics, resume building and mock interviews.
