Program Overview

From Server Basics to Architecting Cloud at Scale

The AWS Cloud Solutions Architect program takes you from the fundamentals of Linux and networking to designing fault-tolerant, secure and cost-optimised architectures that enterprises run in production.

You'll spend most of your time inside a real AWS console — provisioning compute, storage and networks, locking down access with IAM, running managed databases, going serverless with Lambda, and automating everything with Terraform and CloudFormation. By the time you reach the capstone, you'll think and work like a cloud architect, not just a certification candidate.

Every module is taught by trainers who have shipped cloud systems for real companies, so you learn the trade-offs and decisions that textbooks skip. Doubt-solving is live, projects are reviewed one-on-one, and our career team stays with you right up to onboarding at your first cloud role.

Curriculum

A 10-Module Roadmap to Cloud Mastery

Carefully sequenced modules that build from fundamentals to a production-grade capstone. Click any module to see the topics inside.

Cloud computing models (IaaS, PaaS, SaaS), the AWS global infrastructure of regions and availability zones, the shared responsibility model, Linux essentials, file systems, user permissions, SSH, package management and the AWS CLI setup. You'll finish ready to operate confidently on the command line.

EC2 instance types, AMIs, key pairs, security groups, Elastic IPs and auto-scaling groups. S3 buckets, storage classes, versioning and lifecycle rules. EBS volumes and snapshots. Deep-dive into VPC — subnets, route tables, internet & NAT gateways, and load balancing with ELB.

IAM users, groups, roles and policies written in JSON; least-privilege design; MFA; access keys and rotation; AWS KMS encryption; Secrets Manager; security groups vs network ACLs; and an introduction to compliance, auditing with CloudTrail and best practices for a secure account.

Relational databases with Amazon RDS (MySQL, PostgreSQL), multi-AZ deployments and read replicas, automated backups, and Aurora basics. NoSQL with DynamoDB — tables, partition keys, indexes and capacity modes. Caching concepts with ElastiCache and choosing the right database for the job.

Event-driven architecture, writing and deploying Lambda functions, triggers from S3, SNS and SQS, API Gateway to expose REST endpoints, environment variables, IAM execution roles, and building a fully serverless application that scales to zero and costs almost nothing at idle.

Why IaC matters, authoring CloudFormation templates with parameters, resources and outputs, and stack management. Terraform providers, resources, variables, state files, modules and workspaces. You'll provision an entire environment from code and tear it down with a single command.

Docker images, containers, Dockerfiles, registries (ECR) and Docker Compose. Kubernetes architecture, pods, deployments, services, config maps and scaling. Running managed Kubernetes on Amazon EKS and deploying a microservices application across a cluster.

Git and version control workflows, branching strategies, and building continuous integration and delivery pipelines with Jenkins. Automated builds, tests and deployments to AWS, plus an introduction to AWS CodePipeline and CodeDeploy for a cloud-native release workflow.

CloudWatch metrics, dashboards, alarms and log groups; SNS notifications; the Billing console, budgets and Cost Explorer; right-sizing and reserved vs spot instances; the AWS Well-Architected Framework; and practical techniques to keep cloud bills predictable and low.

Design and deploy a complete, production-style architecture end-to-end — highly available, secure, automated and monitored. Then it's interview time: architecture whiteboarding, scenario questions, AWS certification exam practice, resume polishing and mock interviews with cloud architects.
